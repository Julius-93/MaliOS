# MaliOS

## Personal Financial Operating System

MaliOS is a secure personal financial operating system designed to help users manage their money, understand their financial health, achieve financial goals, and access investment opportunities from one seamless platform.

## Vision

To give every person a simple, intelligent and secure view of their entire financial life.

## Core Capabilities

- Financial dashboard
- Income and expense tracking
- Budgeting
- Bank and mobile-money account aggregation
- Net worth tracking
- Financial goals
- Investment portfolio management
- Investment intelligence
- Financial health scoring
- AI financial copilot
- Family financial management
- Financial reports
- Secure authentication and authorization

## Technology

- React
- Node.js
- Express
- PostgreSQL
- Prisma
- React Native
- GitHub

🚧 Early development

## Security

Security and privacy are core architectural requirements of MaliOS. The application will follow recognized application-security practices and applicable data-protection and financial regulations as the product evolves.
